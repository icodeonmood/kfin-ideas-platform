# New wording on the sharing side, for HR's sign-off (lane C)

Written Wednesday 18 Nov 2026 for HR's review of launch-facing copy (SHIP_PLAN §8), to be signed off before Thursday's 17:00 go/no-go. Lane C builds Home, Tell it (the box where a problem is told and the draft forms beside it), Check it, then send it, Edit after sharing, the idea preview pop-up, similar ideas, files, hidden details and voice notes. Everything else on these screens is the design pack's own copy (`1pc-handoff/reference/copy/` and the boards), used as it stands. These are the lines lane C had to add or change, and the places where no line is drawn, so nothing is shown. Some lines come from the pack's written defaults rather than from the boards, and the "Why" column says so. Figures, kinds and places in a line ("2 of 6", "PAN", "page 2", "Folio ••••89") change with each case. Home, Tell it, Edit after sharing and similar ideas are still landing today, so their lines are given as they stand on 18 Nov.
