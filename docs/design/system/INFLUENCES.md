# Where the ideas came from

Every borrowed idea, its source and licence. Nothing here changes the brand: the palette, type, mark and tagline come only from `docs/BRAND.md`. The full record for the first proposal, with commits and the safety scan of each repo, is `docs/design/SOURCES.md` in the app repo; the rows marked "new" below still need adding to it.

| What we took | From | Licence | Copied or referenced |
|---|---|---|---|
| The liquid button: a fill that grows from the pointer and follows it, a turbulent edge from an SVG noise filter driven by pointer speed, and a ring with a recoil on press (new) | Vengeance UI, `liquid-button` (vengenceui.com) | None stated in its registry entry or source file | Referenced only. Rebuilt from its described behaviour in plain JS and CSS; its React/Tailwind source is not used. Its noise frequency (0.035 by 0.08, two octaves) is the one value kept |
| Timelines, staggers, elastic and back eases, grid staggers (new: now used, not only referenced) | GSAP 3.13 (greensock/GSAP) | GreenSock "standard no-charge" licence: free for commercial use; not MIT, Apache, BSD or OFL; prohibits building a competing visual animation builder | Bundled, unmodified, inside `components/bundle.js` with its licence header. Needs one look from Legal |
| What glass should do: bend light instead of scattering it; arrive by modulating its bend, not by fading; flex and light up when pressed; lift controls into glass; float as a layer over content, never glass on glass; a regular and a clear weight, with clear only over bold content; solid under reduced transparency (new) | Apple, "Meet Liquid Glass" (WWDC25) and its design guidance | Principles, not code or assets | Referenced. Our own rules, values and implementation; no Apple asset, icon or shape is used |
| How to do it in a browser: a bezel height function (convex squircle), one ray traced per distance from the edge with Snell's law at index 1.5, the result stored as a displacement map in the red and green channels, applied through `backdrop-filter` (new) | "Liquid Glass in the Browser: Refraction with CSS and SVG" (kube.io) | A published method; its code is not used | Method referenced; implementation is our own (`OnePercentClub.refract`), and adds the colour split, magnify, per-element maps that stretch while resizing, and the rim that follows the pointer. Chromium only, with a blur-and-rim fallback |
| The moves for in-between states: a stepper whose line fills as steps complete, a thumb that stretches between tabs, rows that slide when a table re-sorts (new) | Built with GSAP's timeline, stagger and elastic-ease tools, from its documentation | As GSAP above | Own choreography; no demo code copied |
| A design-quality rubric used to check this edition against common generated-design tells: one-sided accent borders, inconsistent component radii, low-contrast text on colour (new) | Taste Engine | Tool | Used as a checklist; nothing copied |
| A theme is only a set of custom-property overrides, so one component works on any surface: our White and Zed themes, and now the tier dials | Astryx (meta/astryx), theme architecture | MIT | Referenced (the idea; our values) |
| Named motion roles and the rule that reduced motion turns travel into a cross-fade of at most 200 ms on the `move` curve | Astryx, `packages/core/src/motion` | MIT | Referenced |
| Component anatomy and accessibility contracts for Banner, FieldStatus, EmptyState, Toast, AlertDialog, Stepper, Carousel and ProgressBar, behind our Status, PausedBanner, ConfirmInPlace, ChecksRunning, OnesStrip and StrengthMeter | Astryx components | MIT | Referenced |
| The expo-out curve `1.001 − 2^(−10t)`, our `ease-out` | Lenis (darkroomengineering/lenis) | MIT | Referenced (a curve, not code) |
| Optional smooth scrolling on brand pages | Lenis | MIT | Not used yet; waits for the product lead |
| React 18 runtime files in `components/lib/` | React (facebook/react) | MIT | Carried only because this page's preview frames expect them; no component uses React, and the app does not need these two files |

What we did **not** take: any other Vengeance UI component, Astryx's themes (gothic, y2k and the rest are Meta's), its StyleX build, its CLI or its agent skills. None of those packages is installed.
