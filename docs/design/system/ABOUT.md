# Design system snapshot (lane D)

A copy of the 1% Club Design System proposal, kept here so other lanes can read it next to the code. The live, reviewable version with component previews is the claude.ai artifact https://claude.ai/artifact/YBh9eYsRUYpSfK98cBJZeF (private to the product lead until shared). This folder is a proposal: nothing in `apps/web` uses it until the product lead approves it and it is ported (see `HANDOFF.md`).

| File | What |
|---|---|
| `tokens.json` | Colour (White and Zed surfaces), type, space, radius, elevation, motion timings |
| `bundle.css` | The components in plain CSS over the tokens |
| `README.md` | The brand book: the idea, surfaces, colour, type, shape, the three signature devices |
| `MOTION.md`, `STATES.md`, `INFLUENCES.md`, `HANDOFF.md` | Motion rules, the five states, sources, how it reaches the app |
