# KFintech Ideas — company knowledge bundle

Open Knowledge Format (OKF v0.2) bundle. One concept per file; file names are IDs. Written only by the platform's repo writer, from approved events. People change rules and taxonomy through pull requests.

| Folder | What it holds |
|---|---|
| [rules/](rules/index.md) | Machine-read settings: scorecard, priority, thresholds, time limits, routing, reason codes, points, compliance tiers, calendar, redirects |
| [taxonomy/](taxonomy/index.md) | Categories and plays, area tags, LOBs, role families, glossary |
| [ideas/](ideas/index.md) | One file per idea, by year and month |
| [clusters/](clusters/index.md) | Groups of ideas about the same problem |
| [themes/](themes/index.md) | Groups of related clusters |
| [decisions/](decisions/index.md) | Committee and gate outcomes, with reasons |
| [handovers/](handovers/index.md) | Packs sent to the Garage or the fix track |
| [appeals/](appeals/index.md) | Appeals and their outcomes |
| [solutions/](solutions/index.md) | What KFin already runs: the "In the Garage" catalogue |
| [guidance/](guidance/index.md) | Committee guidance and canvas examples |
| [comms/](comms/index.md) | Communication rules and message templates |
| [lenses/](lenses/index.md) | Weekly LOB and role views (counts only) |
| [learning/](learning/index.md) | Corrections, cluster runs, calibration |

Never stored here: personal data, investor or client records, core committee briefs, sealed scores or assessments, the people view.
