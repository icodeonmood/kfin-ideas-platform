# S-02: Sign in

**Route (proposed):** `/sign-in`. **Boards:** `SignIn`, `PhoneSignIn`

## `S-02.purpose` Purpose

Shown only when silent single sign-on is not possible, fails, or a session expires. It always says where the person will land next, and that nothing is lost.

## `S-02.layout` Layout

Desktop: two panels. Left, the form on glass: the brand, the title "Sign in to 1% Club", then the current step. Right, a lit panel with the mark and the tagline "1% spark. 99% sweat." Footer: "1% Club, a KFintech programme".

Phone: a lit colour card at the top holding the logo and title; "Use single sign-on" in the middle; the email field in a bottom sheet with "Send code".

## `S-02.states` States (each is a board state; logic in `L-AUTH.states`)

| State | Content | Primary action |
|---|---|---|
| Enter email | Label "Work email"; field (placeholder name@kfintech.com); help "Use your official KFintech email ID to sign in."; then "or" and "Use single sign-on" (line button) | "Send code" (disabled until the address is a valid work address) |
| Enter code | "Check your email. We sent a 6-digit code to kavya.menon@kfintech.com. It works for 10 minutes." + "Change email"; six code boxes; "You can ask for a new code in 0:45." (becomes "Send a new code" at 0:00); "Not in your inbox? Check Junk, or use single sign-on." | "Sign in" (enabled at 6 digits; also submits automatically when the sixth digit is entered) |
| Wrong code | Same, boxes shake, error under them: "That code didn't match. Check the latest email from 1% Club. 2 tries left." | "Sign in" |
| Signing you in | "Signing you in. With your KFintech account, the same one you use for Outlook and Teams." "Next: Share a problem. You land in the box with the cursor ready. Nothing to find again." "Usually under a second. Still here? Continue" | none (automatic) |
| Could not sign in | "We couldn't sign you in. Your KFintech account didn't answer in time. This is usually a short network hiccup on the office Wi-Fi or VPN. Nothing you typed is lost." "You will still go straight to Share a problem. Or get a code by email instead." "Still stuck? Call the IT service desk on [EXTENSION] and give them this reference: SSO-7F3A, 9:42 am" | "Try again" |
| Session expired mid-draft | "Sign in again to carry on. KFintech apps sign everyone out after 8 hours. Your draft is safe, exactly as you left it." A card: "Draft, saved 9:41 am on this laptop", the title, "You were checking it. Sorting and the folio you hid are kept." "Trouble signing in? Call the IT service desk on [EXTENSION]." | "Send a code to kavya.menon@kfintech.com"; "Use single sign-on instead" (line) |

The `cameFrom` tweak changes only the "Next:" line: from "Share a problem" it names the composer; from a plain "Sign in" link it names Home.

## `S-02.rules` Rules

1. Steps slide forward and back (`F-MOTION.handover`). Focus goes to the first field of each step; on the code step, to the first box.
2. The code boxes follow `C-FIELD.kinds` (paste, auto-advance, numeric keypad, one-time-code autofill).
3. The resend countdown is a `role="timer"` and is not announced every second.
4. After success: go to the kept destination (`P-ROUTES.state`) with the flood hand-over if it is the composer.
5. Field rules and messages: `V-FIELDS.signin`.
